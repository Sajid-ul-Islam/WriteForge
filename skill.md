# AI Skills & Capabilities

WriteForge AI is equipped with specific editorial skills designed to mimic high-level human journalism:

### 1. Editorial Article Crafting
- **Tone Adaptation**: Switches between Persuasive, Formal, Op-ed, Analytical, and Blog styles.
- **Structure**: Automatically generates headlines and organized sub-sections.
- **Context Awareness**: Integrates retrieved facts from the RAG system into the narrative flow.

### 2. Semantic Retrieval (RAG)
- **Multi-format Parsing**: Extracts text from PDF, DOCX, and MD.
- **Vector Search**: Uses `all-MiniLM-L6-v2` embeddings for fast, local semantic lookup.

### 3. Creative Transformation
- **Headline Generation**: Creates 3 distinct, compelling options for any input.
- **Poetry**: Converts factual or raw notes into evocative imagery-rich poems.

### 4. Text Analysis
- **Sentiment Scoring**: Real-time polarity and subjectivity analysis using TextBlob.
